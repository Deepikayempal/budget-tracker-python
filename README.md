# 💰 Budget Tracker Application

## 📌 Project Overview
The Budget Tracker Application is a Python-based project designed to help users manage their personal finances by tracking income, expenses, and budgets.

It provides a simple menu-driven interface and stores financial information using JSON for data persistence.

## 🚀 Features
- Add Income – Record income sources and amounts.
- Add Expense – Track expenses by category.
- Financial Summary – Calculate total income, total expenses, and remaining balance.
- Set Budget – Set a spending limit.
- Budget Alert – Receive a warning when expenses exceed the budget.
- View All Transactions – Display income and expense records with timestamps.
- Data Persistence – Save and retrieve financial data using JSON.
- Input Validation – Handle invalid amounts and prevent negative or zero entries.

## 🛠️ Technologies Used

- JSON

- Datetime Module

## ▶️ How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python budget_tracker.py
```

5. Select an option from the menu to manage your finances.
